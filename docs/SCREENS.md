# 내일은행 (Naeil Bank)

습관을 수명 시간으로 환전하는 은행 — 와이어프레임 33개 화면을 그대로 옮긴 React + PWA 프로젝트.

## 실행

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

- 기준 해상도: **393 × 808** (와이어프레임 393×852에서 상단 상태바 베젤 44px 제외). 화면이 작으면 비율을 유지한 채 축소됩니다.
- 글꼴: **Noto Sans KR** 가변 폰트 1개로 통일 (`public/fonts/NotoSansKR.woff2`, 100~900). 외부 폰트 CDN을 쓰지 않습니다.
- 라우팅: `react-router-dom` (BrowserRouter)
- 상태: `src/state/AppContext.jsx` 하나로 관리 (보호 모드, 연동, 알림, 플랜, 식사, 동의 등)

## 와이어프레임 이후 추가 반영 사항

1. **뒤로가기** — 좌측 상단 `<` 는 실제 히스토리 뒤로가기(`src/hooks/useGoBack.js`).
   링크로 바로 진입해 뒤로 갈 곳이 없으면 각 화면의 fallback 경로로 이동합니다.
2. **베젤 제거** — 상단 상태바(9:41·신호·배터리)와 하단 홈 인디케이터를 모두 삭제했습니다.
   좌표는 와이어프레임 그대로 두고 화면만 44px 끌어올려(`.screen { top: -44px }`) 프레임을 393×808로 줄였고,
   하단 탭바는 항상 화면 맨 아래에 붙습니다.
3. **알림 시각 휠** — 알림 설정의 발송 시각은 굴러가는 휠입니다(`src/components/TimeWheel.jsx`).
   가운데 칸이 선택 값이고 좌우 칸을 누르거나 드래그하면 굴러옵니다. 예) 10:00 선택 → `08:00 09:00 [10:00] 11:00 12:00`.
   00~23시가 끊김 없이 이어집니다.
4. **필수 입력 확인란** — 회원가입·로그인에서 이메일/비밀번호를 비우고 진행하면
   "이메일과 비밀번호는 필수 입력 항목입니다." 확인란이 뜹니다(`src/components/AlertModal.jsx`).
   회원가입은 이메일 형식·비밀번호 8자리·비밀번호 일치까지 확인합니다.
5. **알림 화면** — 홈의 종 아이콘을 누르면 `/notifications` 로 이동합니다.
   새 알림이 있으면 목록을 보여주고(탭하면 해당 화면으로 이동하며 읽음 처리, "모두 읽음" 지원),
   새 알림이 없으면 **"새로운 알림이 없습니다."** 를 표시합니다. 홈의 빨간 점도 새 알림이 있을 때만 켜집니다.

## 3차 수정 사항

- **뒤로가기 재작성** — `history.state.idx` 는 새로고침·HMR 로 초기화되어 뒤로가기가 먹통이 되므로,
  앱이 직접 화면 이동을 기록하도록 바꿨습니다(`NavTracker` + `AppContext.navStack`).
  리다이렉트(`REPLACE`)는 기록을 덮어써서 `/plan → /plan/edit` 같은 되돌이 현상도 없습니다.
  탭 루트(홈·플랜·설정)를 제외한 모든 화면에서 ` < ` 가 직전 화면으로 돌아갑니다.
  이용약관·개인정보 처리방침에도 ` < ` 를 추가했습니다.
- **글꼴 통일** — Noto Sans KR 가변 폰트를 `woff2` 로 변환해 넣고 전 요소에 적용했습니다(Gothic A1 / Inter 참조 제거).
- **명세서** — "BMJ 연구 기반 인증" 을 누르면 논문 출처 화면으로 이동합니다.
- **하단 탭 "식사" 아이콘** — 포크·나이프를 다시 그려 잘리지 않게 했습니다(모든 탭 아이콘 bbox 검사 통과).
- **사진 업로드** — 업로드한 사진이 그대로 화면에 표시됩니다(`PhotoUpload` 공용 컴포넌트).
- **오늘의 식탁 기록** — "카메라 촬영 / 앨범 선택" 버튼을 없애고 사진 영역만 남겼습니다.
  "기록된 오늘의 식탁 보기" 버튼은 위로 올려(하단 탭바와 90px 여유) 잘리지 않습니다.
- **나의 플랜** — 주간 기록의 날짜를 누르면 선택이 그 날짜로 바뀝니다.
- **미래 얼굴 예측** — "미래 얼굴 예측하기" 를 누르면 "오늘의 식탁 기록"과 같은 사진 넣는 화면이 뜨고,
  사진을 올린 뒤 예측을 시작하면 계산 중 화면에 올린 사진이 보입니다. (사진 없이 누르면 확인란 안내)
- **알림 시각** — 칸을 눌러도 선택되지 않던 문제를 고쳤습니다(컨테이너의 `setPointerCapture` 가 `click` 을 가로챔).
- **이용약관** — 하단 "이해했습니다." 버튼을 제거했습니다.

## 4차 수정 사항

- **뒤로가기 진짜 원인 수정** — 헤더의 가운데/우측 정렬 제목 `<span>` 이 폭 393px 로 그려지면서
  뒤로가기 버튼 **위를 덮고 있어** 클릭이 제목에 먹히고 있었습니다.
  제목을 먼저 그리고 `pointer-events: none` 을 줘서 클릭이 항상 버튼에 닿게 했고, 버튼 히트 영역도 24→32px 로 키웠습니다.
  (좌표 기준 히트테스트로 전 화면 재검증 완료)
- **탭 루트 3개 화면의 ` < ` 제거** — 오늘의 식탁 기록 / 잃어버린 시간 되찾기 프로젝트 / 미래 얼굴 예측.
- **회원가입** — "이메일로 연결하기" 삭제, "카카오톡으로 시작하기" 로 문구 변경.
- **로그인** — "카카오톡으로 시작하기" 버튼 추가.
- **일별 수명 명세서** — 바코드를 2.3배(51×24 → 117×55)로 키우고 번호도 함께 키웠습니다.
  아래 항목들 위치와 영수증 카드 높이도 같이 조정했습니다.
- **글씨 크기 통일** — 12 / 13 / 14 / 16 / 18 / 22 / 28 / 38 의 8단계로 정리했습니다(11→12, 15→14, 20→18, 24·27→22).
- **글씨 겹침 제거** — 전 화면 텍스트 상자 교차 검사로 겹치는 곳을 찾아 줄바꿈·폭 조정으로 해결했습니다.
  - 홈 지표 카드: `스크린타임 3.1h` 한 줄 → 이름/값 **두 줄**로 분리
  - 논문 출처: 저널명과 DOI 줄 겹침 해소
  - 나의 시간 흐름: 라벨과 합계 겹침 해소
  - 플랜 처방 카드: 제목과 +시간 칩 겹침 해소

## 5차 수정 사항

- **AI 환산 화면 스크롤** — 절대 위치로 고정돼 있던 시트를 흐름(flow) 배치로 바꿔서
  메뉴를 추가하면 시트가 함께 길어지고, 추가한 항목이 보이도록 자동으로 아래로 스크롤합니다.
- **줄바꿈 시 칸도 함께 늘어남** — 보호 모드처럼 글이 길어져 두 줄이 되는 곳을 flex 배치로 바꿨습니다.
  - 명세서 / 나의 시간 흐름 원장 행: 금액 칸이 두 줄이 되면 **행 전체와 태그 칸이 같은 높이로 늘어나고 내용은 세로 가운데 정렬**
    (영수증 카드 높이도 573 → 607 로 자동으로 늘어남)
  - 오늘의 식탁 기록 카드: 메뉴가 길어지면 카드가 같이 늘어남
  - 홈 "2.1% 어제보다 2시간 증가": 줄바꿈 없이 **가로만 늘어나는** 알약(173×26, 한 줄 유지)
- **로그인** — 카카오 버튼 문구를 "카카오톡으로 연결하기" 로 되돌렸습니다.
- **비밀번호 찾기 2단계 추가**
  - `/login/find` 이메일 주소 입력 → 코드 받기 → 6자리 인증 코드 입력 → 인증 확인
  - `/login/reset` 새 비밀번호 + 확인 → 변경 완료 안내 후 로그인 화면으로
  - 각 단계마다 필수 입력·형식·일치 여부를 확인란으로 안내합니다(성공 안내는 초록 톤).
- **알림창 때문에 뒤로가기가 막히던 문제** — 확인란이 떠 있을 때 ` < ` 를 누르면 딤이 먼저 먹혀
  두 번 눌러야 했습니다. 로그인·회원가입·비밀번호 찾기 화면은 헤더를 알림창보다 위에 그리고,
  뒤로가기 시 확인란을 함께 닫도록 했습니다.

## 6차 수정 사항

- **보호 모드 권장 자동 노출 제거** — "1시간 내 5회 조회" 감지 로직(`recordBalanceView`·`resetViewCount`·조회 시각 기록)을
  전부 삭제했습니다. 화면(`ProtectionSuggestScreen`)과 라우트(`/protection-suggest`)는 코드만 그대로 남겨뒀습니다.
  보호 모드는 이제 **설정 → 보호 모드** 에서만 켜고 끕니다.
- **연구 출처 상세 3장으로 확장** (`src/content/sources.js`)
  1. **수면** — Cappuccio 외, Sleep 2010 (138만 명 메타분석 / 7시간 기준 부족 1시간당 −60분)
  2. **활동 & 식사** — Spiegelhalter, BMJ 2012 (마이크로라이프 / 운동 첫 20분 +60분, 음주 1잔 −30분)
  3. **스크린타임** — Veerman 외, BJSM 2012 (생명표 분석 / 시청 1시간당 −22분)
- **옆으로 넘기기** — "BMJ 연구 기반 인증" 을 누르면 열리는 화면에서 좌우로 스와이프하면
  수면 → 활동 & 식사 → 스크린타임 순으로 넘어갑니다(scroll-snap). 하단에 현재 페이지 점 표시도 있습니다.
- **페이지 표시** — 각 장의 "논문 원문 보기 →" 버튼 아래에 `< 1 / 3 >` 를 두어 화살표로도 넘길 수 있습니다.
- **원문 링크 수정** — 각 장의 버튼이 실제 해당 논문으로 연결됩니다.
  - 수면 → 무료 전문(PMC) `https://pmc.ncbi.nlm.nih.gov/articles/PMC2864873/`
  - 활동 & 식사 → `https://www.bmj.com/content/345/bmj.e8223`
  - 스크린타임 → `https://bjsm.bmj.com/content/46/13/927`

## 7차 수정 사항

- **연구 출처 상세** — 하단의 점(`● ○ ○`) 표시를 없애고 그 자리에 `< 1 / 3 >` 페이지 표시를 넣었습니다.
  "논문 원문 보기 →" 버튼은 페이지 표시 **바로 위**(버튼 708~750, 표시 768)에 붙였습니다.
- **시작 화면 로고** — 인라인 SVG 대신 **이미지 파일**(`public/images/logo.png`, 512×512 투명 PNG)을 씁니다.
  앱 아이콘 모양·색은 그대로이며, 다른 로고 파일이 있으면 이 파일만 교체하면 됩니다.
  (더 이상 쓰지 않는 `AppIcon.jsx` 는 삭제했고, 파비콘용 `public/icon.svg` 는 그대로 둡니다.)
- **시작 화면 문구** — 세로 위치는 그대로 두고 가로만 가운데 정렬했습니다.
- **미래 얼굴 예측** — "미래 얼굴 예측하기" 버튼 바로 위에 연한 색(`#B0A89E`)으로
  "정면으로 얼굴이 잘 보여야 하는 사진이여야 합니다." 안내를 넣었습니다(비교 화면 · 사진 넣는 화면 둘 다).

## 동작하는 기능

- **보호 모드**: 설정 → 보호 모드에서 켜고 끕니다(자동 권장 노출은 제거).
  켜면 명세서·시간 흐름·식사 기록의 마이너스 표기가 `회복 가능 +Nh` 로 바뀝니다(표시 계층만 분기, 데이터는 그대로).
- **로그인/회원가입**: 이메일 형식·비밀번호 길이가 맞지 않으면 로그인 오류 화면.
  회원가입·카카오/이메일 연결 → 개인정보 처리방침 → 3개 항목을 모두 동의해야 통과(미동의 시 "모두 동의해주세요." 알림창).
- **일상 연동**: 수면/걸음/스크린타임 토글, 데이터 연동 관리(Apple 건강·스크린타임·Google Fit) 토글 + 연동됨/미연동 뱃지.
- **명세서**: 항목을 누르면 근거 논문(연구 출처 상세)로 이동, 날짜 선택 바텀시트에서 날짜를 고르면 발급일이 바뀝니다.
- **시간 흐름**: 7일/4주 세그먼트 전환, 항목 탭 → 논문 출처.
- **식사**: 사진 업로드(카메라/앨범) → AI 환산 화면(항목 이름 수정·삭제, 메뉴 직접 추가) → 확정 시 기록 화면.
- **플랜**: 수락 전에는 처방 화면, 수락 후에는 나의 플랜(미션 체크 토글). "플랜 수정하기"로 다시 처방 화면.
- **미래 얼굴**: 좌우 드래그 비교 슬라이더 → 예측 시작 → 계산 중 화면 → 결과 2분할.
- **알림 설정**: 아침 명세서 알림 on/off + 발송 시각 휠(00~23시), 미션·주간 리포트 알림.
- **알림함**: 홈 종 아이콘 → 새 알림 목록(탭하면 해당 화면 이동·읽음 처리) / 없으면 "새로운 알림이 없습니다."
- **데이터 관리**: 항목별 체크 → 계정 및 전체 데이터 삭제 → 확인 모달(동의 체크 필수) → 삭제 시 홈화면2 / 식탁 기록 없음 상태로 전환.
